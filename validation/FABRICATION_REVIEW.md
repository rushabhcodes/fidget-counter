## Reproduce

Install the pinned Bun dependencies with `bun install --frozen-lockfile`; use the mechanical Python requirements, validation/requirements-gerber.txt, KiCad9 CLI/pcbnew and PrusaSlicer2.8.1. Run `bun run build:source`, compare the generated circuit to the saved snapshot, then `bun validation/check-fresh-routing.mjs`, `bun validation/run-fabrication-review.mjs`, `python validation/check-gerber-parity.py`, `bun test`, `bun run typecheck`, `bun run check:assembly` and `bun run check:programming`. The print manifest and printing instructions give actual slicer commands. Audit hashes bind evidence to the final source and exports.
